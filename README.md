# Student Performance Analysis 📊

This project analyzes student marks, study hours, attendance, and sleep hours using Microsoft Excel.

## Analysis Performed
- Mean
- Median
- Range
- Variance
- Standard Deviation
- Correlation
- Regression Analysis

## Key Insight
Students with higher study hours and attendance scored better marks.
